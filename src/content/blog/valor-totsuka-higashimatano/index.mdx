神奈川県内では関東1号店の「横浜下永谷店（港南区）」が大盛況となっていますが、続く**神奈川2店舗目（関東3号店）として「戸塚区東俣野町店（仮称）」の建設計画**が明らかになりました。

現地へ足を運び、開発計画の看板・平面図の調査、敷地の現状撮影を行ってきました。**「開店スケジュール・出店場所・現在の敷地の様子・店舗完成イメージ・競合比較」**を詳しくレポートします。

## 2. 場所はどこ？（Googleマップ・車での出入り注意点）

場所は国道1号線沿い、**旧「ミツバ 横浜研究開発センター」の跡地**です。メルセデス・ベンツ戸塚のすぐ北東側に隣接しています。

### 【重要】国道1号本線からは直接出入り不可
ドライバーが最も注意すべきなのは、**国道1号本線側からは敷地への直接進入・退出ができない設計になっている点**です。

```
【車両アクセス動線のシミュレーション】
                国道1号本線（バイパス）
───────┬───────────────────────────┬───────
       │  ※中央分離帯・ガードレールあり   │
       │    （本線からの直接進入は不可）   │
┌──────┴───────────────────────────┴──────┐
│                                          │
│        バロー戸塚区東俣野町店 予定地      │
│                                          │
└──────┬───────────────────────────┬──────┘
       │  ▲ 車両出入口①                   │ ▲ 車両出入口②
───────┴───────────────────────────┴───────
         旧国道1号（市道東俣野278号線）     市道東俣野36号線
```

- **北西側出入口**：裏手の**「旧国道1号（市道東俣野278号線）」**沿いにメインゲートが設置されます。
- **南東側出入口**：メルセデス・ベンツとの間を通る**「市道東俣野36号線」**側にもサブゲートが設けられます。
- 国道1号上り（戸塚・横浜方面）からも下り（藤沢・小田原方面）からも、側道や旧道を経由して進入するルートになります。

### 店舗設計の特徴
- **屋上駐車場スロープを完備**：敷地手前の広い平面駐車場に加え、建物の外周からスロープで屋上へ登る**「屋上駐車場」**を備えています。平面と屋上を合わせて**計221台**の大型収容力を誇ります。
- **平屋（ワンフロア）の食品メガ売場**：店舗棟は地上2階建て（実質1階が売場、2階相当が屋上駐車場）の構造。階段やエレベーターの上り下りなく、ワンフロアで効率よく買い回りができる実用的な動線です。

## 5. 戸塚・藤沢エリアのスーパー勢力図とバローの勝算

戸塚区南部から藤沢市北東部にかけてのエリアは、激安系スーパーや大型商業施設がしのぎを削る激戦区です。

| スーパー名 | 店舗特徴 | バロー東俣野町店との違い |
| :--- | :--- | :--- |
| <b>バロー (東俣野町店)</b> | <b>生本マグロ・飛騨牛・焼きたてパン</b>の圧倒的品質と低価格。駐車場221台 | <b>生鮮とお惣菜のクオリティ</b>で週末のごちそう需要を独占 |
| <b>ロピア (戸塚店・湘南めぐみが丘等)</b> | 大容量パック・メガ盛り肉・オリジナル冷凍食品の圧倒的安さ | ロピアはまとめ買い・メガ盛り。バローは鮮魚の鮮度とベーカリーで差別化 |
| <b>業務スーパー (戸塚原宿店)</b> | 輸入食品・冷凍調味料・乾物の格安仕入れ | 乾物・冷凍品は業スー、毎日の生鮮野菜・刺身・肉はバロー |
| <b>サミットストア (横浜岡津店等)</b> | 充実した普段使いの品揃えと深夜営業 | 平日の即席おかずはサミット、休日の贅沢買いはバロー |

戸塚・藤沢エリアの住民にとって、ロピアや業務スーパーとは違った**「魚屋・肉屋の専門店並みの鮮度を持ちながらスーパーの価格で買える」**というバローの存在は、生活のクオリティを劇的に引き上げる選択肢になります。
