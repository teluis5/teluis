東海・北陸発のスーパー「バロー」による、東京都内初進出となる「スーパーマーケットバロー本羽田店（仮称）」の計画概要を端的にまとめました。

## 1. 店舗概要スペック一覧

| 項目 | 店舗データ・詳細 |
| :--- | :--- |
| <b>店舗名</b> | スーパーマーケットバロー本羽田店（仮称） |
| <b>事業者</b> | 株式会社バロー（岐阜県多治見市） |
| <b>所在地</b> | 東京都大田区本羽田1-23-25 |
| <b>出店形態</b> | 居抜き出店（2025年12月末閉店の「オリンピック本羽田店」跡地） |

| <b>オープン予定</b> | 2026年晩秋頃 |

## 2. 出店場所（Googleマップ）とアクセス

産業道路や第一京浜からも近く、多摩川を挟んで川崎市とも隣接する好立地です。

## 4. バローの3大強み

1. <b>圧倒的な鮮魚力</b>（「魚のバロー」と評される市場直送魚・本格寿司）
2. <b>強力な自社PB</b>（低価格の「valor select」、上質な「valor plus」）
3. <b>売場6,600㎡のメガスケール</b>（都内では希少な週末ファミリー向け大型店）
