## 2. フロア構成と入居テナント：食品・家電・薬局・100均が揃うメガ商業施設へ！

2025年12月末に惜しまれつつ閉店した「オリンピック本羽田店」の広大な建物をフルリノベーションし、**「1階：食のテーマパーク（バロー）」＋「2階：ノジマ・スギ薬局・セリアの強力専門店街」**という、暮らしに必要なすべてが揃う複合商業施設に生まれ変わります。

```
【バロー本羽田店のフロア構成イメージ】
┌──────────────────────────────────────────────┐
│ 屋上・立体駐車場：約300台収容（雨天でも濡れずに店内直結）     │
├──────────────────────────────────────────────┤
│ 2階：大型専門店フロア                                         │
│      ・デジタル家電専門店「ノジマ」                           │
│      ・ドラッグストア＆処方せん調剤「スギ薬局」（12/1開局）   │
│      ・人気100円ショップ「Seria（セリア）」                   │
├──────────────────────────────────────────────┤
│ 1階：スーパーマーケット「バロー」食品メガフロア               │
│      ・生本鮪ブーメランや丸魚が並ぶ巨大鮮魚コーナー           │
│      ・岐阜直送の飛騨牛・国産若鶏が並ぶ精肉コーナー           │
│      ・100円台焼きたてパン「北欧倶楽部」ベーカリー             │
│      ・名物デリカ・寿司の「中部フーズ」惣菜バイキング         │
└──────────────────────────────────────────────┘
```

### ① 1階：バロー本体 ＆ 北欧倶楽部 ＆ 中部フーズ
1階ワンフロアすべてがバローの食品売場となります。
バローの最大の特徴は、単なる安売りスーパーではなく**「デスティネーション・ストア（わざわざ目的地として行くスーパー）」**を掲げている点です。

- **店内ベーカリー「北欧倶楽部」**：店内で生地から焼き上げるパンが常時60〜80種類並び、名物のアップルパイやホテルブレッド、100円台の焼きたて総菜パンが驚異的なコスパを誇ります。
- **デリカ・寿司「中部フーズ」**：バロー直営の惣菜ブランド。店内で握るデカネタの本格海鮮寿司や、出汁の効いた厚焼き玉子、自家製カツ丼など、デパ地下顔負けのお惣菜が並びます。

### ② 2階：ノジマ ＆ スギ薬局（12/1調剤開局） ＆ セリア
2階フロアには、暮らしを支える3大大型テナントの出店が確定しています。

- <b>家電量販店「ノジマ バロー本羽田店（仮）」</b>：家電・スマートフォン・PC関連・電球やインクなどの消耗品相談まで幅広く対応。
- <b>ドラッグストア「スギ薬局 本羽田店」</b>：日用品・医薬品・コスメに加え、<b>処方せん受付を行う調剤薬局が「2026年12月1日」に開局</b>。買い出しの合間に病院の薬を受け取れる圧倒的な利便性が生まれます。
- <b>100円ショップ「Seria（セリア）バロー本羽田店」</b>：おしゃれな雑貨やキッチン用品、収納グッズで絶大な人気を誇るセリアが入居。日常の細かな買い物も館内で完全に完結します。

## 3. 大田区・羽田周辺の競合スーパーとの徹底比較

大田区南東部（本羽田・萩中・糀谷周辺）は、OKストアやライフ、マルエツなどがひしめくスーパー激戦区です。バローが参入することで勢力図がどう変わるのか、特徴を比較しました。

| スーパー名 | 価格帯 | 強み・特徴 | バロー本羽田店との棲み分け |
| :--- | :---: | :--- | :--- |
| <b>バロー (本羽田店)</b> | <b>安〜中</b> | <b>生鮮（生本鮪・飛騨牛）・惣菜・ベーカリー＋家電・薬・100均</b>。駐車場300台 | <b>週末のまとめ買い・ごちそう・ワンストップ買い出し</b>に圧倒的強み |
| <b>オーケー (仲六郷店等)</b> | <b>最安</b> | ナショナルブランド（調味料・加工食品）の地域最安値 | 加工食品や日配品の普段買いはOK、生鮮やお惣菜はバロー |
| <b>ライフ (大森南店等)</b> | <b>中</b> | バランスの良い品揃えと深夜営業、PB「スマイルライフ」 | 平日仕事帰りの利便性はライフ、休日のワクワク感はバロー |
| <b>マルエツ (新糀谷店)</b> | <b>中</b> | 駅近の立地とTポイント経済圏、手頃なお弁当 | 駅直結の徒歩アクセス重視ならマルエツ |

バローの最大の武器は**「生鮮食品の圧倒的なエンタメ性と専門性」**、そして**「ノジマ・スギ薬局・セリアを揃えたワンストップ性」**です。加工食品のディスカウントに強いオーケーとは完全にキャラクターが異なり、**「魚やお肉、お惣菜をごちそうクオリティで安く買い、ついでに薬や100均、日用品も揃えたいファミリー層」**にとって最高の拠点となります。
